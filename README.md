# StudyFlow — Student Planner SaaS

A responsive student planner mini-project built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with task statistics and progress
- Create tasks with subject, due date, time, and priority
- Mark tasks complete and filter by status
- Timetable preview based on scheduled tasks
- Responsive blue-themed UI for desktop and mobile
- Saves tasks in the browser using `localStorage`
- SaaS-style Free/Premium interface mockup

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in your browser.

No build tools or installation are required.

## Publish with GitHub Pages
1. Create a public repository named `studyflow-student-planner` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After GitHub Pages finishes deploying, the site should be available at:
   `https://guntha.github.io/studyflow-student-planner/`

The live URL will work only after the repository exists and GitHub Pages is enabled.
